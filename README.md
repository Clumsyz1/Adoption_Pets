# 🐾 ระบบรับเลี้ยงสัตว์เลี้ยง (Pet Adoption System)

โปรเจกต์นี้เป็นแอปพลิเคชัน Java Desktop (Swing GUI) สำหรับบริหารจัดการศูนย์รับเลี้ยงสัตว์เลี้ยง ช่วยให้ผู้ดูแลสามารถจัดการข้อมูลสัตว์และดำเนินการรับเลี้ยงตามกฎเกณฑ์ที่กำหนดได้อย่างมีประสิทธิภาพ

## 📋 ฟีเจอร์หลัก (Features)

* **จัดการข้อมูลสัตว์เลี้ยง**:
    * ลงทะเบียนสัตว์เลี้ยงใหม่ (สุนัข, แมว) พร้อมระบุชื่อ อายุ และประเภท
    * ดูรายชื่อสัตว์ที่ยังว่าง (Available)
* **ระบบคัดกรองการรับเลี้ยง (Adoption Rules)**:
    * **ตรวจสอบรายได้**: ลูกค้าต้องมีเงินเดือน 30,000 บาทขึ้นไปจึงจะสามารถยื่นเรื่องขอรับเลี้ยงได้
    * **ลูกค้าทั่วไป (Walk-In)**: สามารถรับเลี้ยงได้เฉพาะ **สุนัข** เท่านั้น
    * **ลูกค้า VIP**: สามารถรับเลี้ยงสัตว์ได้ทุกประเภท แต่ต้องมียอดบริจาคสะสม 500 บาทขึ้นไป
* **บันทึกข้อมูลถาวร (Persistence)**:
    * บันทึกข้อมูลสัตว์ลงไฟล์ `Pets.txt`
    * บันทึกประวัติการรับเลี้ยงที่สำเร็จลงไฟล์ `adoption_requests.txt`

## 🛠 โครงสร้างโปรเจกต์ (Structure)

ไฟล์หลักในระบบประกอบด้วย:

* **View & Controller**:
    * `PetAdoptionGUI.java`: หน้าจอหลักของโปรแกรม (Main Class) ใช้สำหรับแสดงผลและรับค่าจากผู้ใช้
* **Data Management**:
    * `DataManager.java`: จัดการการอ่านและเขียนไฟล์ข้อมูล (`.txt`)
* **Models**:
    * `Pet.java`, `Dog.java`, `Cat.java`: โมเดลข้อมูลสัตว์เลี้ยง
    * `Customer.java`: คลาสแม่ของลูกค้า มีลอจิกตรวจสอบเงินเดือน
    * `WalkInCustomer.java`: ลูกค้าทั่วไป (Override เงื่อนไขรับเลี้ยง)
    * `VIPCustomer.java`: ลูกค้า VIP (เพิ่มเงื่อนไขยอดบริจาค)
    * `AdoptionRequest.java`: จัดการสถานะคำร้องขอรับเลี้ยง

## 🚀 วิธีการติดตั้งและใช้งาน (Installation & Usage)

### ความต้องการระบบ (Requirements)
* Java Development Kit (JDK) 8 หรือสูงกว่า

### ขั้นตอนการรันโปรแกรม
1.  **Compile**: เปิด Terminal หรือ CMD ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
    ```bash
    javac *.java
    ```
2.  **Run**: รันโปรแกรมด้วยคำสั่ง:
    ```bash
    java PetAdoptionGUI
    ```

### คู่มือการใช้งานเบื้องต้น
1.  **เพิ่มสัตว์เลี้ยง**: กรอกข้อมูล รหัส, ชื่อ, อายุ, ประเภท ในช่องด้านบน แล้วกดปุ่ม "เพิ่มสัตว์"
2.  **รับเลี้ยง**:
    * เลือกสัตว์จากรายการ "รายชื่อสัตว์ที่ยังว่าง"
    * กดปุ่ม "รับเลี้ยงสัตว์" (สีเขียว)
    * เลือกชื่อสัตว์ที่ต้องการ และกรอกข้อมูลลูกค้า (ชื่อ, เงินเดือน, เบอร์โทร)
    * หากเป็น **VIP** ต้องระบุยอดบริจาคด้วย
    * ระบบจะแจ้งผลการอนุมัติทันที

## 📂 ไฟล์ข้อมูล (Data Files)

ระบบจะสร้างไฟล์เหล่านี้อัตโนมัติเมื่อเริ่มใช้งาน:
* `Pets.txt`: เก็บข้อมูลสัตว์ทั้งหมด (รหัส, ชื่อ, สถานะ)
* `adoption_requests.txt`: เก็บ Log ประวัติการรับเลี้ยงที่ได้รับการอนุมัติแล้ว
